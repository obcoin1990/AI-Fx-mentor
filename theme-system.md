# Theme System (Dark & Light Mode)

## Overview
The platform supports dark and light themes using:
- next-themes
- TailwindCSS dark: classes

## Behavior
- Auto-detect system theme
- Manual toggle via ThemeToggle component
- Smooth transitions

## Color Tokens
- Light: bg-white, text-black
- Dark: bg-[#0A0F1C], text-white, cyan/purple accents

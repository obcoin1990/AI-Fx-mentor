# Features

## Core Capabilities
- Upload forex chart screenshot (PNG/JPG)
- AI detects:
  - Trend direction
  - Swing highs & lows
  - Support & resistance zones
  - Chart patterns (double top, channel, etc.)
- AI generates:
  - Possible buy/sell zones
  - Stop-loss & take-profit suggestions
  - Risk–reward ratio
  - Mentor-style explanation

## Future Additions
- Multi-timeframe analysis
- Auto-draw levels on the image
- Browser extension for TradingView
- Save analysis history to user dashboard
